# Counter-Strike 1.6 Browser Clone (Prototype)

A lightweight single-file JavaScript game inspired by Counter-Strike 1.6 gameplay loops:

- CT vs T themed round gameplay
- WASD movement + mouse aim + click shooting
- Health, ammo, money, buy menu
- Different gun profiles (Glock, MP5, AK-47, M4A1, AWP)
- Round timer and win/loss conditions

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000> in your browser.

## Controls

- `WASD`: Move
- Mouse: Aim
- Left click: Fire
- `R`: Reload
- `B`: Open buy menu
